# MiniMax-H3 — NF4 for LoRA training

NF4 (4-bit) version of [MiniMax-H3](https://huggingface.co/MiniMaxAI/MiniMax-H3) (transformer, Qwen3-VL-32B text encoder and VAEs, 41 GB instead of 498 GB), used by [AcademiaSD LoRAlab Trainer Studio](https://github.com/AcademiaSD/AcademiaSD_LoRAlab-TrainerStudio) to train MiniMax-H3 LoRAs and RefMods on consumer GPUs. The trainer downloads it automatically.
