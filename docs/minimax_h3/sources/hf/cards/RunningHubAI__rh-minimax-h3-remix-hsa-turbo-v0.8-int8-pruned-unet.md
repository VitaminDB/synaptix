## About this model

<p>This model is a pruned version further optimized based on MiniMax H3 Remix HSA turbo v0.8. It is also used to improve the visual performance of MiniMax H3 when generating high-dynamic videos with low steps, making it suitable for dynamic content creation such as martial arts, chases, explosions, and fast camera movements.<br/>Based on INT8 quantization and model pruning, this version focuses more on lightweight deployment and generation efficiency. It is recommended to use it with the Remix Easy H3 second-sampling workflow for the best results.<br/>This version does not contain NSFW content.<strong></strong></p>
