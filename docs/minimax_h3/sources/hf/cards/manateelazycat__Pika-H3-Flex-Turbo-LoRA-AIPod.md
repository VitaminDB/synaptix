# Pika H3 Flex Turbo LoRA for AI Pod

Built on MiniMax H3, with Pika / Mellis, Inc. Flex adapters and LightX2V turbo distillation.
The selected model is the full 4-step FL2VA adapter at strength 1, Euler, CFG 1,
video shift 6 and audio shift 3. Two/eight-step, lite and Ref2VA variants are not
claimed by this package. Model parameters are separately mounted read-only.

Model derivative terms: MiniMax H3 Community License Agreement. Source code retains
Apache-2.0 and the respective third-party notices under licenses/.
This repository delivers the small deployment controller, model-free Thor runtime,
source, verification evidence, and the minimal LPK after its release gates pass.
