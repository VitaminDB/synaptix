# Repackaged MiniMax-H3 Turbo LoRAs — ComfyUI Compatibility
Working with the stock LoraLoader — no custom nodes, no custom sampler.

This repository contains third-party ComfyUI compatibility conversions of the original **MiniMax-H3 Turbo LoRAs**.

Original LoRA: [larryvrh/MiniMax-H3-Turbo-Lora](https://huggingface.co/larryvrh/MiniMax-H3-Turbo-Lora)

Original LoRA: [DMAD 4 step Turbo Lora](https://huggingface.co/ZhengmingYu/DMAD/tree/main/minimax_h3)

Both DMAD loras work on **4 steps, euler/simple, video shift=12, audio shift=2**.
