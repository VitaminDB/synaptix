# Производительность моделей

Сводная таблица замеров всех используемых моделей: дата, скорость (ток/с) и/или время генерации, условия.
Карта — RTX 5090 Laptop, 24 ГБ; ОЗУ 94 ГБ. Строка добавляется при каждом новом замере — прежние не стираются,
чтобы было видно «было → стало». Подробности по отдельным моделям — в их документах (ссылки в конце).

Правила записи:
- «источник»: `CLI` — пример или команда `synaptix`, холодная карта; `служба` — через synaptixd (обычно медленнее:
  прогретая карта, вытесненный кэш страниц, соседние модели); `журнал` — из журнала службы на живой задаче.
- Время — на весь ролик/картинку/трек, если не сказано «шаг» или «этап».
- Замер без условий (размер, длина, шаги, квант) не записывается.
