Порт torch.package-пакетов Silero TTS v5 на synaptix: сеть, вокодер и весь фронтенд (без Python и TorchScript).

`unpack_q_model`; фразы омографов — разбором паттерна с самопроверкой обратной сборкой).

## Сеть

Предсказатели длительности/высоты: эмбеддинг + голос (+ тип/фокус по флагам модулей) → 4 FFT (64, пост-норма,
внимание 2 головы, свёртки k9/k1) → Linear. Такотрон: кодировщик 4 FFT 128, высота — свёртка k3, регулятор
длины `int(d + 0.5)`, декодер «песочные часы» (pre-FFT → avgpool ×3 → FFT → Linear 128→384 вверх + остаток →
post-FFT), Linear → мел 192 (80 кадров/с). Вокодер: свёртка k7 → ConvNeXt ×8 → Linear 2402 → |X| = min(eˣ, 100),
фаза → ISTFT `same` (n_fft 2400, hop 600) → 48 кГц; 24/8 кГц — PQMF-анализ (2/6 полос, первая полоса,
tanh при выходе за ±1).

Повторены особенности оригинала: первый «короткий» слой декодера считается и отбрасывается; обнуление высоты на
пунктуации в корне не срабатывает (cumsum по оси батча, цикл пуст); колпаки длительностей (начало 5, у v5_6 при
эмфазе 20; конец 7, предпоследний 13, третий с конца ≤ 13).

## Фронтенд

Переводы строк, нижний регистр, тире, `ext_alph` (грузинский/армянский → кириллица), фильтр символов, `^`;
омографы (v5_6: фразы-шаблоны, контекст чистится, окно 300; v5…v5_5: всё предложение), BERT батчем с `[PAD]`
без маски (как оригинал); расстановщик (v5_6 делит и по пунктуации, старые — по пробелам, «-то» не трогает).
Типы предложений (wh/general/alternative/tag-вопрос, восклицание). Добавлено: числа словами (русские голоса) —
в алфавите модели цифр нет. SSML, эмфаза `**слово**` и фокус `*слово*` пока не поддержаны.

## Сверка (`examples/silero_audit.rs` против `reference/silero_ref.py`)

Последовательности, типы и длительности — бит в бит на всех 12 пакетах; высота тона 1e-6, мел 9e-7, вокодер 3e-6,
звук 1.5e-5…2.5e-4 (48/24/8 кГц). Ударения и омографы: 25 подобранных строк и 265 предложений Википедии —
совпадение 100 % для старого и нового фронтенда. Whisper распознаёт русские версии дословно.
Скорость (CPU ПК): RTF ≈ 0.008–0.01, фронтенд ~1 мс на предложение.
